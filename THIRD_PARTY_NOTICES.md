# Third-party notices and data provenance

## Source data

The original campaign extract is not included in this repository. It contains user-level behavioral records and is not established as publicly redistributable. No license or permission to republish it is asserted here.

The public repository contains only:

- independently written analysis code;
- deterministic synthetic data and fixtures;
- non-identifying aggregate benchmark values;
- original documentation written for this portfolio project.

It does not contain source notebooks, reports, teaching materials, message bodies, logos, videos, external-drive links, user identifiers, addresses, or source-derived row-level samples.

## Synthetic data

Synthetic records generated by this project are fictional and are intended solely to test the public analysis workflow. They should not be interpreted as observations from a real campaign.
